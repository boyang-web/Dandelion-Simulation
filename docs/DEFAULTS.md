# 生产默认值（2026-11-20）

生产启动（`index.html`，不带 `?dev=1`）**不创建开发控制台**，因此不会读取
`localStorage`、也不会出现 `DEV` 按钮。下面这些源码默认值就是线上画面实际
使用的值；开发者启动仍然可以覆盖它们并保存到本地。

## 不在控制台暴露的固定值

- 后处理高光滚降 `shoulder = 0.34`；
- 日月循环 `timeCycle = 120 s`，主场景初始时间 `0.4`（远景预览 `0.42`）；
- 风场内部：`radiusFactor 0.34`、`speedFloor 70`、`speedRange 1400`，草的方向低通 /
  一致性闸门保持原值；
- 蒲公英：`seedResponseBase 0.34`、`regrowVar 0.16`、`seedLifeVar 9`、单颗种子展开 `1.6–2.3 s`、
  `quiverBase 0.011`、`quiverGain 0.085`；
- 离体种子尺寸 `0.90–1.08`，0.45 秒内从花头原始尺寸过渡到个体尺寸；
- 主茎静风摆幅约 `0.004–0.008 rad`，阵风时最多再叠加 `0.028 rad`。

> 发回来，再替换本表中的值并重新提交。
