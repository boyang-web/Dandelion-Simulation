# 《风经过的地方》产品设计文档

> 一个关于风、种子、能力与留影的放松向摄影冒险  
> 版本：v0.2 · 2026-11-23 · 设计草案  
> 工程：`dandelion/`（Three.js 环山谷地）

## 这份草案的来历

这是 2026 年 11 月 23 日写下的设计稿。那时的问题很具体：如果鼠标离开了花头，玩家还能怎样吹动种子？我们试着让玩家自己滚过草地。草叶倒下去，种子从旁边的花头飞出来，站远些也能看见风走过哪儿。

草案里还设想了升空、安放相机和五个能力谜题。下面的时长、平台与关卡安排是当时的目标。现在能玩的版本见[仓库首页](../README.md)。

### 操作与反馈

玩家滚过花旁，花头就会掉种子。飞高一点，可以看见坡后面的空地，也能换个角度拍照。遇到谜题时，先让草叶、花头和光线给出线索；看不清的操作才写成提示。玩家可以停下来等风，也可以绕回去再试。

## 2. 这趟旅行有多长

草案预留了二十到三十分钟，安排五处地标。每到一处，玩家用刚学会的本领解题，拍下一张明信片。收齐后可以回山谷继续拍照。

### 2.2 目标玩家

- 喜欢 *Journey*、*Alba*、*Pokémon Snap*、*Townscaper*、*Everything* 的玩家；
- 喜欢在游戏里拍照、看风景、不被打扰的人；
- 想在 10–30 分钟内获得一段完整情绪体验的人；
- 喜欢把自己拍的游戏照片发给朋友的人。

### 2.3 情绪曲线

| 阶段 | 情绪 | 对应能力 |
| --- | --- | --- |
| 开场 | 好奇、轻微迷失 | 滚动 + 单株蒲公英 |
| 老树 | 被回应、想记录 | 相机 |
| 风车 | 发现规律、协作感 | 多株 |
| 塔顶 | 自由、开阔 | 起飞 |
| 枯泉 | 温柔、复苏 | 种子恢复 |
| 山脊 | 回望、完成 | 控制时间 |
| 结束 | 不舍、愿意再逛 | 自由摄影模式 |

## 3. 核心循环

### 3.1 微循环（约 10 秒）

```
滚动/升空 → 带起风 → 草与种子响应 → 观察 → 构图 → 按下快门/录制
```

### 3.2 场景循环（约 4–6 分钟）

```
到达锚点 → 读懂能力锁 → 使用当前能力 → 解锁新能力 → 环境变化 → 拍下明信片
```

### 3.3 元循环（完整流程）

```
5 个锚点 → 5 个能力 → 5 张明信片 → 最终联系表/片尾 → 自由摄影模式
```

| 循环层 | 玩家动作 | 世界反馈 | 情绪回报 |
| --- | --- | --- | --- |
| 微循环 | 移动、升空、种植 | 草浪、种子、尘埃、光 | “我经过了这里” |
| 场景循环 | 解一个温柔的谜 | 门打开、风车转、泉眼复苏 | “我改变了这里” |
| 元循环 | 收集明信片 | 场景逐渐恢复生机 | “我留下了一条路” |

## 4. 能力成长与能力锁

### 4.1 能力总表

| 顺序 | 能力 | 玩家动词 | 解锁地点 | 能力锁 | 摄影意义 |
| --- | --- | --- | --- | --- | --- |
| 0 | 地面滚动 | WASD / 摇杆移动 | 初始 | 无 | 地面低机位、草浪前景 |
| 0 | 单株蒲公英 | 点击/轻点种植 | 初始 | 无 | 第一朵花的特写 |
| 1 | **相机** | 安放、取景、拍照、录制 | 老树 | 第一株蒲公英唤醒老树，藤门打开；相机在树洞中 | 全流程的记录工具；取景器可显示风线与种子回声 |
| 2 | **多株** | 同时种下 3 株（后续可升到 6 株） | 风车底座 | 三个风眼；用 3 株蒲公英点亮，风车转动 | 花圈、风车与三株花的构图 |
| 3 | **起飞** | 长按空格 / 按住升空键 | 风车上升气流 | 气流内升空键首次临时可用；长按升到画廊/塔顶，取得风羽后永久解锁 | 俯拍、穿行、空中长镜头 |
| 4 | **种子恢复** | 长按 R / 恢复键，复苏枯萎蒲公英 | 枯泉 | 复苏枯死的蒲公英，长出藤桥，打开通往山脊的路 | 枯荣对比、复苏瞬间、藤桥前景 |
| 5 | **控制时间** | 拖动太阳/月亮，或使用时间盘 | 北坡日晷 | 把日影调到刻痕，打开最终视野 | 黄昏、夜景、萤火虫、长曝光感 |

> 说明：这里的“相机”指**可安放、可录制的胶片相机**，不是始终存在的第三人称镜头。第三人称镜头从开场就有；相机是一个能力。

### 4.2 能力锁地图

```
出生点 (0, 1.2)
  │  滚动 + 1 株蒲公英
  ▼
老树 (-34, -22) ── 解锁【相机】
  │  第一株花唤醒树，藤门打开
  ▼
风车 (42, -40) ── 解锁【多株】
  │  三个风眼 + 三株蒲公英 → 风车转动
  ▼
风车画廊/塔顶 (42, -40, y≈2.8–8) ── 解锁【起飞】
  │  上升气流 → 气流内临时可用升空键 → 风羽
  ▼
枯泉 (0, 45) ── 解锁【种子恢复】
  │  复苏枯死蒲公英 → 藤桥 → 通往北坡
  ▼
北坡日晷 (-9, 114.5) ── 解锁【控制时间】
  │  调到黄昏 → 日影对准刻痕 → 最终视野
  ▼
最终联系表 / 自由摄影模式
```

### 4.3 每个能力的“解锁即使用”

拿到一项本领，就在附近安排一道要用它的谜题。

| 能力 | 获得方式 | 第一次使用 | 永久效果 |
| --- | --- | --- | --- |
| 相机 | 老树开花后，树洞中的相机落到地面 | 拍下第一朵花，胶片卷开启 | 随时安放/取景/拍照/录制 |
| 多株 | 风车底座的“种子合唱”石，把一颗种子分成三颗 | 在三个风眼各种一株 | 同时存在 3 株（枯泉后 6 株） |
| 起飞 | 风车转动后出现的上升气流；进入气流后升空键首次临时可用 | 长按升空到画廊/塔顶，取得风羽 | 任意地点可借风升空 |
| 种子恢复 | 枯泉中的“回种”种子 | 复苏枯死的蒲公英，长出藤桥 | 可复苏任意枯萎蒲公英 |
| 控制时间 | 日晷中的“日种” | 把时间调到黄昏，对准刻痕 | 自由拖动日月/时间盘 |

### 4.4 能力锁的设计原则

1. **一个锁只考一个新动词 + 一个旧动词**
   - 老树：种植 + 风；
   - 风车：多株 + 风；
   - 画廊/塔顶：起飞 + 气流；
   - 枯泉：恢复 + 观察；
   - 日晷：时间 + 取景。

2. **锁在能力源旁边**
   - 不做长距离回头路；拿到能力后 30 秒内就能用上。

3. **锁的答案是可见的**
   - 三个空风眼、上升的尘土、枯萎的蒲公英、日晷上的刻痕；
   - 不需要猜隐藏按钮。

4. **没有失败**
   - 时间不对、顺序不对、位置不对，只是“还没发生”；
   - 不做限时、不做扣血、不做资源耗尽。

5. **何时需要相机**
   - 取景器可以显示风线、种子回声和可交互物的微光；
   - 但不用相机也能完成谜题，只是更费观察。

6. **能力永久保留**
   - 解锁后不会失去；
   - 后续场景可以自由组合旧能力，形成“我变强了”的感觉。

7. **能力锁的终点是画面**
   - 每个锁解开后，环境进入一个独特的、短暂或永久的美术状态；
   - 这是明信片的拍摄时机。

### 4.5 UI 随能力生长

不做一上来就铺满按钮的 HUD。界面跟着动词一起长出来：

| 已解锁 | 桌面 | 手机 |
| --- | --- | --- |
| 初始 | WASD、点击种植、拖动镜头、滚轮缩放 | 左摇杆、右侧拖拽镜头、轻点种植 |
| 相机 | 增加 C（相机）、P（拍照）、R（录制） | 增加相机按钮、快门/录制按钮 |
| 多株 | 种植上限 1 → 3，出现微弱的种子点数 | 种植按钮出现 3 个种子点 |
| 起飞 | 空格长按升空 | 右下角出现升空按钮 |
| 种子恢复 | R 近枯萎植物时变为“恢复” | 出现上下文恢复按钮 |
| 控制时间 | 太阳/月亮可拖动，出现时间盘 | 出现时间滑盘/时间盘 |

> 拿到新能力时，再显示对应按键。

### 4.6 存档与进度

```js
progress = {
  abilities: {
    camera: false,
    multiPlant: false,
    lift: false,
    restore: false,
    time: false
  },
  maxPlants: 1,          // 1 → 3 → 6 → 15（自由模式）
  anchors: {
    oldTree: 'locked' | 'awake' | 'photographed',
    windmill: 'locked' | 'turning' | 'photographed',
    tower: 'locked' | 'reached' | 'photographed',
    spring: 'dry' | 'restored' | 'photographed',
    sundial: 'locked' | 'aligned' | 'photographed'
  },
  postcards: [],
  settings: {}
}
```

- `localStorage` 存进度和设置；
- `IndexedDB` 存照片/视频 Blob；
- 刷新后能力、锚点状态、明信片保留；
- 不做账号、不做云存档（V1）。

### 4.7 自由摄影模式

完成第 5 个锚点后：

- 所有能力保留；
- 种植上限回到当前场景允许的最大值（15）；
- 时间可自由控制；
- 5 个锚点仍然可以拍摄，但不再强制；
- 胶片卷保留，可继续导出；
- 显示一张“联系表”（Contact Sheet）：5 张明信片 + 玩家自己拍的照片；
- 按钮：`继续漫游` / `重新开始`。

这是产品的“通关后沙盒”，也是最适合分享的状态。

## 5. 世界与路线

### 5.1 路线坐标

坐标基于当前 `valleyHeight(x, z)` 高度场；高度为设计时的近似值，最终以运行时采样为准。

| 地点 | 坐标 (x, z) | 地形高度 | 距上一站 | 作用 |
| --- | --- | --- | --- | --- |
| 出生点 | (0, 1.2) | ≈ 0.02 | — | 初始滚动、单株教学 |
| 老树 | (-34, -22) | ≈ 0.88 | 41 m | 相机、第一张明信片 |
| 风车 | (42, -40) | ≈ 2.45 | 78 m | 多株、风车能力锁 |
| 风车画廊（塔顶） | (42, -40, 画廊) | 画廊 ≈ 2.8 m；塔顶 ≈ 7–8 m | 垂直 | 起飞、风羽 |
| 枯泉 | (0, 45) | ≈ 0.20 | 95 m | 种子恢复、藤桥 |
| 北坡日晷 | (-9, 114.5) | ≈ 10.55 | 70 m | 控制时间、最终明信片 |

总步行距离约 **284 m**；纯移动约 45 秒，实际体验由观察、解谜、拍摄拉开到 20–30 分钟。

### 5.3 地形约束

当前角色移动约束：

- 最大半径 `118 m`；
- 最大高度 `30 m`；
- 最大坡度 `0.44`；
- 地面高度来自 `world.heightAt(x, z)`。

相机安放建议限制：

- 半径 ≤ 130 m；
- 坡度 ≤ 0.5；
- 相机脚架落点高于地形 0.05 m；
- 不允许放进山体或水面；
- 塔顶锚点允许放在风车画廊/平台。

### 5.4 资产复用

已有但主场景尚未加载的资产：

## 6. 玩家与风

### 6.1 风滚草状态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| Idle | 静止 | 轻微呼吸、枯枝微颤、阴影稳定 |
| Roll | WASD/摇杆 | 绕垂直速度轴滚动，扬尘，草倒伏 |
| Gather | 长按升空键 | 旋转加快，草被压弯，尘土环形成 |
| Lift | 持续按住 | 缓缓升起，风线/花粉螺旋上升 |
| Glide | 松开升空键 | 缓慢下降，可水平微调 |
| Land | 接触地面 | 轻弹、草浪扩散、种子震起 |
| Restore | 靠近枯萎植物 | 身体发出暖光，种子回流 |
| Time | 时间盘 | 光色变化，影子移动，萤火虫/星点变化 |

### 6.2 风的两层

1. **自然风**：一直存在，缓慢吹动草、种子、花粉、萤火虫；让世界在玩家静止时仍然活着。
2. **玩家风**：由滚动、升空、落地产生；强度更高、范围更局部；是解谜和摄影的主要工具。

关键规则：

- 玩家**不被自己的风推动**，避免越滚越快的正反馈；
- 玩家风可以推动蒲公英种子、草、尘埃、花粉、萤火虫；
- 玩家风在视觉上要“看得见”：风线、尘带、草叶倒伏、种子尾迹；
- 自然风与玩家风叠加，但玩家风有更高的优先级和更清晰的局部形状；
- 现有桌面的“鼠标滑过起风”在 V1 中降级为轻微的环境扰动，不再作为解谜主风源；主风源始终是风滚草。是否完全保留，由“移动即风”的感知测试决定。

### 6.3 视觉反馈

- 滚动：身后一条低矮尘带，草向两侧倒伏；
- 升空：脚下尘土环 + 螺旋花粉 + 风线；
- 落地：一圈草浪 + 种子被震起；
- 恢复：枯萎植物由灰转绿，种子从地面回流到花头；
- 时间：光色、影子长度、星星/萤火虫密度同步变化。

## 7. 升空系统

### 7.1 输入

- 桌面：长按 `Space`；
- 手机：按住右下角升空按钮；
- 起飞能力解锁前，升空键只在风车的上升气流内临时可用；取得风羽后永久可用；
- 松开即进入滑翔下降；
- 空中仍可用 WASD/摇杆微调水平方向。

### 7.2 阶段

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| Gather | 0.35 s | 旋转加速、草压弯、尘土环、低频风声 |
| Lift | 按住期间 | 向上加速，最大上升速度约 4 m/s |
| Glide | 松开后 | 重力约 4.5 m/s²，缓慢下降，水平控制保留 |
| Land | 接触地面 | 轻弹、草浪、种子震起、无伤害 |

### 7.3 建议参数（可调）

| 参数 | 初始值 |
| --- | --- |
| 最大高度 | 25 m（相对地面） |
| 上升加速度 | 8 m/s² |
| 最大上升速度 | 4 m/s |
| 下降重力 | 4.5 m/s² |
| 空中水平控制 | 地面的 0.65 |
| 空中阻尼 | 1.5 /s |
| 落地回弹 | 0.3 m |

### 7.4 镜头

- 第三人称镜头平滑跟随；
- 升空时保持 FOV 不变，避免眩晕；
- 限制俯仰角，保持地平线稳定；
- 相机不穿地，沿用 `groundAt + clearance`；
- 提供“减少动态”选项：降低旋转、关闭快速 FOV 变化。

### 7.5 验收

- 30 秒连续升空/滑翔不晕；
- 落地柔和，没有坠落伤害；
- 升空能明显改变构图（地面 → 俯拍）；
- 空中仍能感知风滚草的位置和朝向。

## 8. 相机与取景

### 8.1 相机能力

- 老树开花后，树洞中的**胶片相机**落到地面；
- 玩家走近拾取，解锁相机能力；
- 相机是一台小三脚架 + 镜头的风格化道具，可安放、可收回；
- 相机能力解锁后，胶片卷、拍照、录制、导出全部开启。

### 8.2 取景模式

V1 采用**单活动相机**：

1. 按 `C` / 点相机按钮进入取景模式；
2. 地面出现相机幽灵预览，点击/轻点安放；
3. 拖动改变朝向，滚轮/捏合改变焦距（FOV 约 28°–65°）；
4. 安放后主渲染相机切换为这台相机；
5. 玩家仍然控制风滚草，进行“表演”；
6. 按 `R` 录制，按 `P` 拍照，按 `Esc` 退出取景；
7. 再次按 `C` 可回到第三人称，相机留在原地。

**为什么 V1 不做画中画（PIP）？**

PIP 需要同时渲染主视角和相机视角，而当前风场是屏幕空间管线，两个相机下的草叶风纹会不一致。V1 先用单活动相机，保证风、天空、草叶在取景画面里完全一致；PIP 作为 V1.5 的技术目标。

单活动相机下的补偿：

- 风滚草离开画面时，屏幕边缘出现一个很淡的方向指示；
- 玩家可以拖动镜头重新找回主体；
- 取景模式随时可以退出，不锁死。

### 8.3 取景辅助

- 三分线；
- 地平线提示；
- 主体在画面内时，边缘出现微光；
- 录制时隐藏所有 HUD，只保留很小的 REC 点；
- 取景器可显示：
  - 风线/气流；
  - 种子回声；
  - 可交互物的微光（风眼、枯死蒲公英、日晷刻痕）。

草案允许玩家自行选择是否打开取景器。

### 8.4 建议机位

| 锚点 | 建议机位 | 构图 |
| --- | --- | --- |
| 老树 | (-44, -32)，低机位看向树根与树冠 | 树占上三分之一，山谷在背景 |
| 老树特写 | (-24, -14)，近景低角度 | 风滚草与第一朵花 |
| 风车 | (52, -54)，低机位看向风车 | 风车与转动叶片逆光 |
| 风车侧景 | (28, -52)，侧向 | 三株蒲公英形成前景 |
| 塔顶 | 画廊高度，俯拍或平视 | 风车叶片/山谷/风滚草俯冲 |
| 枯泉 | (-12, 36)，略高机位 | 枯泉、藤桥、复苏前后 |
| 北坡 | (-20, 120)，朝山谷中心 | 风滚草剪影 + 山谷 + 夕阳 |

以上只是建议，玩家可自由安放。

## 9. 录制与导出

### 9.1 规格

| 类型 | V1 规格 | 说明 |
| --- | --- | --- |
| 照片 | 1920×1080 PNG | 可后续支持 2×/4K |
| 视频 | 1280×720，30 fps，5/8/10 秒 | WebM（VP9）优先，MP4 回退 |
| 画幅 | 16:9 | 9:16 作为 V1.1 |
| 音频 | V1 静音导出 | V1.1 接入 Web Audio 录制 |
| 文件命名 | `wind-photo-001.png` / `wind-clip-001.webm` | 带时间、锚点元数据 |

### 9.2 捕获合成器（关键）

当前页面的视觉分层：

```
CSS 天空/日月/星空/夜色/金色光/暗角/颗粒
        ↓（在 canvas 后面）
WebGL 主场景 canvas（透明背景）
        ↓
萤火虫独立 canvas
        ↓
DOM UI
```

`renderer.domElement.toDataURL()` 或 `canvas.captureStream()` **只能拿到 WebGL 主场景**，会丢掉 CSS 天空、日月、星空、萤火虫和 UI 外的氛围层。

因此必须新增 **Capture Compositor**：

```
输出 2D canvas
  1. 天空渐变（来自 sky.lightState / 当前相机）
  2. 日月辉光/圆盘 + 星空
  3. WebGL 主场景 canvas
  4. 萤火虫 canvas
  5. 夜色/金色滤镜、暗角、颗粒（可选）
  6. 无 UI
```

- 照片：`output.toBlob('image/png')`；
- 视频：`output.captureStream(30)` + `MediaRecorder`；
- 天空绘制接口建议由 `sky.js` 暴露：`sky.paintCaptureSky(ctx, camera, width, height)`，复用现有星图与 lightState；
- 如果录制相机与主相机不同，日月/星空必须按录制相机重新投影；
- V1 单活动相机下，主相机就是录制相机，`sky.sync(camera)` 可保持屏幕与导出一致。

### 9.3 录制流程

1. 安放相机，调整构图；
2. 按 `R` / 录制按钮；
3. 3–2–1 倒计时；
4. 录制 5/8/10 秒，画面上只保留 REC 点；
5. 自动停止，生成 Blob；
6. 存入胶片卷；
7. 可立即预览/导出，或继续漫游。

### 9.4 导出与分享

- 照片：`<a download>`；
- 视频：优先 `navigator.share({ files })`，否则 `<a download>`；
- 不支持 `File` 分享的浏览器：下载；
- iOS Safari 必须实测 `MediaRecorder`；不支持时回退为“仅照片”；
- 不把视频上传服务器，V1 完全本地。

### 9.5 存储

- 照片/视频 Blob 存 `IndexedDB`；
- 元数据存 `localStorage`；
- V1 胶片卷上限 12 条，超出提示删除；
- `URL.revokeObjectURL` 及时释放；
- 刷新后胶片卷保留。

### 9.6 验收

- 导出的照片包含天空、草地、蒲公英、萤火虫、后处理，不含 UI；
- 导出的视频在 Chrome/Safari 可播放；
- 录制期间主场景不崩、不闪黑；
- 照片 ≥ 1920×1080；
- 视频 5–10 秒，文件大小可接受（720p 约 5–15 MB）。

### 14.2 活动相机与后处理

`post.js` 已支持活动相机：

- 渲染时传入当前活动相机并更新 `uTanHalf`、`uSunDirView` 等 uniform；
- `main.js` 在第三人称与安放的胶片相机之间切换 `activeCamera`，后处理与萤火虫层同步切换；
- V1 单活动相机：同一时刻只用一个相机渲染，避免双相机风场不一致；
- V1.5 的 PIP 需要双相机渲染、风场按相机重算，属于后续技术目标。

### 14.3 风场与相机的一致性

当前风场是**屏幕空间**的：

- 指针轨迹存在屏幕坐标；
- 草的弯曲 uniform 也依赖屏幕空间；
- 换一个相机看同一片草，风纹可能对不上。

所以：

- V1 不做双相机同时渲染；
- 玩家风源需要按活动相机重新投影，或改为世界空间；
- 中期目标：把玩家风源做成世界空间样本，再按相机转换，支持 PIP 和自由机位；
- 这是相机/录制功能的最大技术风险之一。

### 15.3 兼容性

- 桌面：Chrome / Edge / Safari 最新；
- 手机：iOS Safari、Android Chrome；
- `MediaRecorder` 支持差异：先检测，失败回退照片；
- `file://` 模式可运行场景，但导出/下载可能受浏览器限制，完整功能建议 `http://`；
- 横屏优先，竖屏可用。

## 16. MVP / 垂直切片

### 16.1 MVP 范围（建议）

只做前 3 幕：

1. **老树**：单株、相机、第一张明信片；
2. **风车**：多株（1 → 3）、三株点灯、风车转动；
3. **风车画廊/塔顶**：上升气流、起飞、风羽、塔顶明信片。

时长约 10–15 分钟，包含：

- 滚动 + 风源反馈；
- 长按升空 + 滑翔 + 落地；
- 相机安放/取景/拍照/录制/导出；
- 能力状态与存档；
- 手机摇杆 + 升空 + 相机按钮；
- 胶片卷 + 3 张明信片；
- 捕获合成器（天空/场景/萤火虫）。

### 16.2 MVP 不做

- 枯泉、种子恢复；
- 日晷、控制时间；
- 6 株/15 株上限；
- PIP 双相机；
- 音频录制；
- 滤镜库/多机位/视频剪辑；
- 社交/账号/云端；
- 9:16 画幅。

### 16.3 垂直切片路线

```
出生点 → 老树（相机） → 风车（多株） → 塔顶（起飞） → 塔顶俯瞰/结束
```

终点给一个“继续探索”的钩子，为第 4/5 幕留白。

## 18. 验收标准

### 18.1 产品

- [ ] 首次进入 10 秒内，玩家能通过移动看到草的反应；
- [ ] 5 分钟内，玩家能种下第一株、获得相机、拍下第一张照片；
- [ ] 10–15 分钟内完成 MVP 三幕；
- [ ] 每个能力锁都能在不看攻略的情况下被读懂；
- [ ] 卡住时没有失败/惩罚，只有环境提示；
- [ ] 每个锚点都有独特的画面和明信片；
- [ ] 通关后进入自由摄影模式，所有能力保留。

### 18.2 能力锁

- [ ] 没有能力时无法绕过 gate；
- [ ] 获得能力后 30 秒内可以立刻使用；
- [ ] 不出现软锁/死锁；
- [ ] 刷新后能力与锚点状态保留；
- [ ] 相机取景器提示不会替代玩家观察，只是辅助。

### 18.3 相机与导出

- [ ] 相机可安放、瞄准、变焦、收回；
- [ ] 取景画面与最终导出画面一致；
- [ ] 照片 ≥ 1920×1080，含天空/萤火虫/后处理，不含 UI；
- [ ] 视频 5–10 秒，720p/30fps，可播放；
- [ ] iOS Safari 有可用回退；
- [ ] 录制时帧率稳定，不闪黑。

### 18.4 移动与升空

- [ ] WASD 与摇杆移动手感一致；
- [ ] 长按升空/滑翔/落地无眩晕；
- [ ] 空中仍可控制方向；
- [ ] 落地无伤害；
- [ ] 降低动态选项有效。

### 18.5 手机

- [ ] 摇杆、镜头、升空、快门、相机按钮无手势冲突；
- [ ] 单手可移动，另一只手可取景；
- [ ] 安全区/刘海/横竖屏正常；
- [ ] 录制/导出可用或有明确回退。

### 18.6 质量

- [ ] 桌面 60fps（高画质）；
- [ ] 手机 30fps（低画质）；
- [ ] 无 JS 报错；
- [ ] `file://` 可浏览场景，`http://` 可完整导出；
- [ ] 胶片卷删除后存储释放。

## 19. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
| --- | --- | --- | --- |
| 捕获合成器与 CSS 天空不一致 | 高 | 高 | 先做 M0；由 `sky.paintCaptureSky` 复用 lightState/星图；对照截图调色 |
| iOS MediaRecorder 不可用/格式异常 | 高 | 高 | 早期真机测试；失败回退照片 + 明确提示 |
| 双相机风场不一致 | 中 | 高 | V1 单活动相机；V1.5 再做世界空间风源/PIP |
| 升空导致晕动症 | 中 | 中 | 高度限制、镜头平滑、固定 FOV、减少动态 |
| 能力锁让放松体验变紧张 | 中 | 中 | 无失败、单动词谜题、环境提示、90 秒软提示 |
| 能力锁顺序/软锁 | 中 | 高 | 线性能力顺序、永久解锁、锚点状态机、自动测试 |
| 新资产/谜题导致范围膨胀 | 高 | 中 | MVP 只做 3 幕；第 4/5 幕后置 |
| 手机性能不足 | 中 | 中 | 低画质档、录制 720p、无 PIP、减少草密度 |
| 自风反馈导致速度失控 | 中 | 中 | 玩家免疫自己的风；只影响环境 |
| 胶片卷存储配额 | 低 | 中 | 12 条上限、IndexedDB、删除释放 |
| 相机安放 UX 复杂 | 中 | 中 | 幽灵预览、三分线、边缘指示、随时退出 |
| 时间能力与现有太阳拖动冲突 | 中 | 中 | 能力 flag 控制；未解锁时禁用拖动；取景时间盘 |

### 22.4 术语

- **锚点（Anchor）**：场景中的能力锁/拍照点。
- **能力锁（Ability Gate）**：需要某个能力才能打开的环境谜题。
- **明信片（Postcard）**：锚点事件后拍下的代表性照片/短片。
- **联系表（Contact Sheet）**：通关后的照片总览。
- **玩家风（Player Wind）**：由风滚草移动/升空产生的局部风。
- **自然风（Ambient Wind）**：一直存在的低频环境风。
- **单活动相机（Single Active Camera）**：同一时刻只用一台相机渲染，保证风/天空一致。
